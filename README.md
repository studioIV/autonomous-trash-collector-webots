# Autonomous Trash Collector (Webots)

Προσομοίωση αυτόνομου ρομπότ συλλογής απορριμμάτων σε περιβάλλον πισίνας. Το KUKA youBot εντοπίζει τέσσερα χρωματιστά αντικείμενα, τα προσεγγίζει, τα πιάνει με την αρχική του δαγκάνα και τα αφήνει στον κάδο που μεταφέρει επάνω του.

## Εκτέλεση

1. Εγκαταστήστε το Webots R2025a ή συμβατή νεότερη έκδοση και Python 3.
2. Ανοίξτε το `worlds/trash_collector.wbt` στο Webots.
3. Πατήστε **Run**. Ο controller `trash_collector` ξεκινά αυτόματα.
4. Για χειροκίνητο έλεγχο και debugging, ανοίξτε το `http://127.0.0.1:8765` όσο τρέχει η προσομοίωση.

Το world χρησιμοποιεί επίσημα `EXTERNPROTO` αρχεία του Webots R2025a από το Cyberbotics GitHub, οπότε η πρώτη φόρτωση απαιτεί πρόσβαση σε αυτά ή ήδη διαθέσιμη cache του Webots. Ο controller χρησιμοποιεί μόνο τη Python standard library και το Python API του Webots.

## Πώς λειτουργεί

- Η μπροστινή κάμερα αναγνωρίζει τους τέσσερις στόχους με κανόνες χρώματος. Δεν χρησιμοποιείται εκπαιδευμένο μοντέλο AI.
- Τρεις αισθητήρες απόστασης βοηθούν στην αποφυγή εμποδίων κατά την κίνηση.
- Η FSM οργανώνει την αναζήτηση, προσέγγιση, ευθυγράμμιση, σύλληψη, ανύψωση, μεταφορά και απόθεση.
- Το manual panel επιτρέπει έλεγχο της βάσης, του βραχίονα και της δαγκάνας, καθώς και προβολή κατάστασης για δοκιμές.
- Τα μηνύματα terminal καταγράφουν γεγονότα της αποστολής και ενδεικτικές τιμές εμπιστοσύνης του controller.

Τα αντικείμενα συλλέγονται με τη σειρά κίτρινο, κόκκινο, πράσινο, μωβ. Ο τρέχων controller χρησιμοποιεί επίσης βαθμονομημένες στάσεις και πληροφορία θέσης από το Webots Supervisor για μέρη της διαδικασίας. Η αναγνώριση εικόνας βασίζεται σε χρώμα και δεν πρέπει να παρουσιαστεί ως γενική AI object detection.

## Αρχεία

- `worlds/trash_collector.wbt`: περιβάλλον, ρομπότ, κάδος, εμπόδια και τέσσερα απορρίμματα.
- `controllers/trash_collector/trash_collector.py`: Python controller, FSM, κάμερα, αισθητήρες, χειρισμός και webserver.
- `controllers/trash_collector/control_panel.html`: browser panel για manual controls.
- `docs/rompotikiteliko.docx` και `docs/rompotikiteliko.pdf`: τελική γραπτή εργασία.
- `docs/Autonomous_Trash_Collector.pptx`: παρουσίαση με τα αρχικά γραφικά.
- `docs/Autonomous_Trash_Collector_reviewed_manual_controls.pptx`: αναθεωρημένη παρουσίαση με διαφάνεια για το manual panel.

Το demo βίντεο αναφέρεται στην παρουσίαση: https://youtu.be/ULplpxjzaOo

## Περιορισμοί

Η προσομοίωση έχει σχεδιαστεί και βαθμονομηθεί για τον συγκεκριμένο κόσμο και τα τέσσερα αντικείμενα. Η αλλαγή θέσεων, γεωμετρίας ή φωτισμού μπορεί να χρειαστεί νέα ρύθμιση της προσέγγισης και της ανίχνευσης.
